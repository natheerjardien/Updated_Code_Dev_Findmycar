# Parkitech

Parkitech is a smartparking system for the Emeris NMB parking

## Installation

Clone project or download zip file, open in Visual Studio Code

In VS code terminal for Mobile App :

```bash
cd iot_Parkitect
cd mobileApp
npm start 
```
In VS code terminal for Web App :

```bash
cd iot_Parkitect
cd SecurityWeb
npm run dev 
```
